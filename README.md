# relatorio_final
📝 Sobre o Projeto

Este repositório contém a solução para o "Desafio de Projeto - Atualizando Relatório Financeiro com Foco na Experiência do Usuário". O objetivo principal foi refatorar o primeiro relatório criativo desenvolvido, aplicando conceitos de design visual e usabilidade para melhorar a forma como os usuários interagem e interpretam os dados financeiros.

🎯 Objetivo

Modificar o relatório financeiro original, priorizando a Experiência do Usuário (UX). A reformulação levou em consideração a estética, a clareza da informação e a fluidez na leitura dos dados, aplicando (e quebrando de forma consciente) regras de design para trazer mais criatividade e impacto visual ao dashboard.


🚀 Melhorias Realizadas

Adequação e reestruturação do layout inicial.

Modificação e aprimoramento de visuais chave (ex: gráfico de área).

Criação de uma nova matriz para descrição detalhada de vendas.

Ajuste fino na estilização dos visuais e no tema da página.

Padronização visual aplicada à segunda e terceira páginas, mantendo a consistência do design estabelecido na primeira página.

💡 Destaque Criativo

Como abordado no desafio, as regras de design não são leis rígidas. A criatividade do relatório vem justamente de entender esses princípios fundamentais (posicionamento, contraste, proporção) e saber os momentos exatos de sair da curva para tornar a visualização de dados mais interessante e engajadora.

Projeto desenvolvido como parte de desafio de aprimoramento em Data Visualization e UX.
